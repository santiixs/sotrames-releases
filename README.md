# Sotrames Recepción · Instaladores

Este repositorio solo contiene los **instaladores** de la app de escritorio de Sotrames. No contiene código.

- Descarga: [última versión](https://github.com/santiixs/sotrames-releases/releases/latest) → `Sotrames-Recepcion-Setup-X.Y.Z.exe`.
- Los equipos que ya tienen la app instalada **se actualizan solos**.
- Las versiones se publican automáticamente desde el repositorio privado de la plataforma.
